# PuddlePals

## Quiz facts (`public/game/quiz-facts.js`)

- Every Who’s That Pal? fact must fit only one pal. When adding a pal, check
  every existing fact against her, and reword or drop any that now fit more
  than one pal (e.g. "lives in ponds" or "divides by binary fission" once a
  second protist does too). Do this without asking.
- Each fact names its pal, so the quiz can blank the name out.
